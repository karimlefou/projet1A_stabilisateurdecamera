# Projet 1A : Stabilisateur Brushless

**Équipe** : Vous + AMR  
**Encadrant** : M. Dumas

## 📌 Contexte
Stabilisation  d'un axe pour caméras légères (<1kg) utilisant des moteurs brushless.

## 🛠 Solution
- **Moteurs** : T-Motor MN3508  
- **Contrôle** : STM32 + IMU MPU-6050  
- **Algo** : PID temps-réel (<50ms)
